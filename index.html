Что такое сайт?

Сайт (веб-сайт) — это совокупность связанных веб-страниц, доступных в интернете и объединённых под одним доменным именем. Веб-страницы могут содержать текст, изображения, видео, аудио и другие мультимедийные элементы.

Сайты могут быть статическими, где контент редко изменяется, или динамическими, где контент обновляется регулярно.

Структура сайта

Главная страница

Это «лицо» сайта, отправная точка для посетителей. Здесь размещают логотип, название сайта, краткое описание тематики и другие элементы.

Разделы и категории

Крупные блоки информации, посвящённые определённым темам. Например, в интернет-магазине: «Женщины», «Мужчины», «Дети».

Подразделы

Используются для дальнейшей детализации информации, создают иерархическую структуру, облегчающую поиск нужных данных.

Страницы

Это «кирпичики» сайта, которые содержат конкретную информацию: текст, изображения, видео, формы обратной связи.

Меню

Навигация, которая помогает пользователям ориентироваться на сайте и находить нужную информацию. Может быть главным, боковым или в футере.

Перелинковка

Ссылки между страницами внутри сайта, улучшающие навигацию и SEO-оптимизацию.

Таблицы на сайте

Таблицы на сайте — это специальный элемент, который предназначен для систематической организации данных в виде строк и столбцов.

Элементы таблицы

Ячейка — минимальная единица таблицы, содержит данные (текст, картинки и т.д.)

Строка — совокупность ячеек, расположенных рядом по горизонтали

Колонка — совокупность ячеек, расположенных друг под другом по вертикали

Заголовок — текстовая строка для названия таблицы или её описания
